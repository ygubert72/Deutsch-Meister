Упражнение 3: Перевести предложения. Перед существительными ставим неопределенный артикль (ein, eine).

1. У меня есть сестра. – Ich habe eine Schwester.
2. У тебя есть кошка – Du hast eine Katze.
3. У него есть машина.
4. У нее есть велосипед.
5. У нас есть дом.
6. У Вас (Sie) есть машина.
7. У вас (Ihr) есть ребенок.
8. У него есть комната.
9. У нее есть кошка.
10. У меня есть книга.
11. У тебя есть жена.
12. У нас есть корабль.
13. У них есть комната.
14. У Вас (Sie) есть кошка.
15. У тебя есть сестра.
16. У них есть машина.
17. У тебя есть бабушка.
18. У него есть квартира.
19. У нее есть дом.
20. У тебя есть квартира.

________________________________

Упражнение 4: Следим за подходящим местоимением – может не совпадать с русским языком (die Katze – sie, das Auto – es, Das Kind – es).

1. У нас есть машина. Она новая. – Wir haben ein Auto. Es ist neu.
2. У меня есть кошка. Она красивая.
3. У тебя есть корабль. Он большой.
4. У вас (Ihr) есть бабушка. Она старая.
5. У него есть ребенок. Он маленький.
6. У меня есть сестра. Она веселая.
7. У нее есть корабль. Он медленный.
8. У нас есть квартира. Она новая.
9. У меня есть дом. Он красивый.
10. У тебя есть комната. Она большая.
11. У меня есть книга. Она интересная.
12. У него есть велосипед. Он маленький.
13. У них есть сестра. Она молодая.
